# 論文の英語 単語帳

https://shinfrog.github.io/paper-english-wordbook/

構造ヘルスモニタリング（車両と橋の連成振動）の英語論文 691 本の本文によく出る単語・専門語・連語・定型表現 1,508 項目の単語帳です。スマートフォンのブラウザで開けます（ホーム画面に追加すると、アプリのように使えます）。

- 項目ごとに、日本語の意味と短い説明、品詞と分類、出る論文の数、よく組む語を載せています。
- 論文の文（例文）は含めていません。
- 日本語の意味と説明は AI（Claude）が書いたもので、一部だけを論文での使われ方と照らして見直しています。
- 覚えた度合いの記録は、使っているブラウザの中（localStorage）にだけ保存されます。

このリポジトリには公開用の `index.html` だけを置いています。作り直しの道具と項目の元データは研究室の中で管理しています。
